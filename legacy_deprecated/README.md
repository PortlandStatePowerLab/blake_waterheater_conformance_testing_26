# legacy_deprecated

Old, deprecated, broken, incomplete, or reference-only project material.

## Belongs here

- Old scripts kept for reference
- Deprecated source trees
- Generated legacy files preserved for review
- Broken or incomplete historical work

## Does not belong here

- Active station operation scripts
- Required runtime inputs for active scripts
- New generated data
- Files that future operators should use without review

## Rule

Nothing in this folder should be treated as active unless it is reviewed and moved back into the active project tree.
