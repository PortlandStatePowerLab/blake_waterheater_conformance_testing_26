# Test Records

This folder stores observed test results, pass/fail notes, command outputs and verification
    evidence from WH1 lab testing.

## Folder purpose

- Use this folder for real test outputs, dated lab notes, meter readings, screenshots,
    and pass/fail records
- Use 'sensor_scaling_checks/' for flow, temperature, ADC, and transmitter scaling tests.

## Rule

A deployment procedure should say what to run

A test record should say what actually happened when it was run.
