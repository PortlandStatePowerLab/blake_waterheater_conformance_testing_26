# data

Data files used by WH1 scripts and analysis workflows.

## Rules

Required CSV inputs must be tracked in Git or generated by tracked code.

Scripts must not silently depend on hand-created local CSV files.

Generated runtime CSVs should go under `data/generated/`, `data/raw/`, or another documented output folder.

Large raw CSV archive policy is TBD with the lab lead. Until then, large generated data should not be committed accidentally.

## Folder guide

- `generated/` — generated CSVs and intermediate data products.
- `raw/` — large raw station captures or experiment logs.
- `combined/` — merged or combined CSV outputs.
