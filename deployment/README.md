# Deployment

This folder contains operator instructions for preparing and testing the staged
WH1 runtime on a Raspberry Pi. The commands are documentation only; they were
not executed during staging.

Use this order:

1. Read `../DEPLOY_MANIFEST.md`.
2. Copy only manifest-listed runtime files.
3. Run `pi_setup/I2C_CHECK_COMMANDS.md`.
4. Run `test_run_order/FIRST_PI_TEST_SEQUENCE.md`.
5. Do not enable GPIO output until review items are closed.
