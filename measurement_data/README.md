# Measurement data

Measured or source datasets used by station and analysis workflows.

Required CSV inputs must be tracked in Git or generated by tracked code. Scripts
should not silently depend on hand-created local CSV files. Large raw CSV archive
policy remains a lab-lead decision; do not commit large generated data by accident.

- `measurement_data/raw/` - station measurements and experiment captures.
- `measurement_data/combined/` - merged measurement datasets that retain measurement meaning.
- `measurement_data/generated/` - legacy-compatible intermediate datasets; prefer
- ->`../generated_results/` when an artifact is derived rather than measured.

## NOTICE

Derived plots, reports, and processed data belong in `../generated_results/`;
operational logs belong in `../runtime_logs/`.

Add a new subfolder only when real files justify a distinct category.
